## 📌 Project Overview

The **Drum Kit Web App** is an interactive browser-based application that allows users to play drum sounds using their keyboard or mouse.

Each key triggers a different drum sound, enabling users to create simple rhythms and experiment with beats in real time.

This project is built to practice **core frontend development skills** using HTML, CSS, and JavaScript.

---

## 🚀 Features

* 🖱️ Play drums using mouse clicks
* ⌨️ Keyboard support (w, a, s, d, j, k, l)
* 🔊 Multiple drum sounds
* ✨ Button animation on interaction
* ⚡ Instant audio feedback

---

## 🎮 How to Use

You can play the drum kit by:

* Clicking on the drum buttons
* Pressing the following keys on your keyboard:

```
w → Tom 1
a → Tom 2
s → Tom 3
d → Tom 4
j → Snare
k → Crash
l → Kick
```
